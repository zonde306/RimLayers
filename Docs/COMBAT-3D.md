# 三维战斗、角度掩体与跨层灾害

2026-10-20 · RimWorld **1.7.4982 rev1280 / Waylith / .NET 10** · RimLayers 0.1.4 开发候选。

选中射手，进入原版攻击模式，再切到目标楼层。瞄准面板显示该目标层的有效射程、身体暴露比例、能否开火和最早障碍物；绿色线是可用射线。部分身体被遮挡时仍能射击，暴露比例就是一次三维掩体通过率。固定炮台用原版强制攻击/自动索敌；有人炮台仍需操作员真实到岗。

## 射程与身体暴露

普通直射武器：

```text
有效射程 = 原射程 × clamp(1 + 0.1 × (射手层 − 目标层), 0.8, 1.2)
```

向下一/两层为 110%/120%，向上一/两层为 90%/80%；同层不变。最小射程、射手精度和武器精度的距离仍是实际水平距离，不把扩展射程当近距离，也不修改伤害或穿甲。曲射、投掷和迫击炮不套高度倍率。

每层逻辑高度为 **3**。沙袋与路障的独立逻辑高度为 **1.0**，原版 `fillPercent=0.55` 保留，不把概率直接解释为物理高度。其他物体延续既有高度映射；完整墙占满一层。旋转后的全部占地都进入碰撞，楼板/屋顶是水平阻挡面。

跨层直射对 Pawn 使用三档身体高度 × 三档横向位置，共九个确定性代表点。站立高度随体型变化，倒地/卧姿更低；横向位置沿射线的垂直方向分布。逐条检查枪口到身体的完整路径，包括射手自己的掩体、目标旁掩体、中途建筑与中间层楼板。

- 低打高时，前缘沙袋通常挡住更多身体；俯射可能越过低处掩体顶部。
- 侧射或绕后只受实际路径上的掩体影响，目标身后的沙袋不提供保护。
- 枪口高于己方掩体时能合法射击；俯角过陡会打中自己的掩体或平台，不新增向平台外探身。
- 全部采样点被挡时不能直射。部分可达时允许射击；瞄准线选可达点，面板还可显示受阻采样线中的最早障碍物。
- 同层普通射击继续使用原版掩体规则。

发射仍经过原版 `Verb_LaunchProjectile.TryCastShot`，保留射手精度、武器散布和强制偏移。跨层三维掩体只抽取一次身体采样点：无遮挡点射向身体，受阻点的实际弹道先撞实体。该发射不再叠加原版二维掩体随机分支；散布后的路线仍检查实际障碍，掩体受击进入原生 `Impact/TakeDamage`。

## 人物、自动炮台和操作员

共享 `CombatService.SolveWeapon` 提供射程、直线/曲线、暴露和首个碰撞结果。原版命中报告、人物射位查询、炮台射击与瞄准显示使用该结果。

人物射位搜索同时考虑可达楼面、原版危险/区域/预订条件、移动成本、对敌暴露和自己的防护。现在可射击、移动后可射击、需追击是不同条件；无上下楼路线不阻止合法远程交火。固定炮台不执行人物移动逻辑。自动炮台候选范围覆盖高度增加的射程，实际射击仍逐目标检查倍率和遮挡。

炮台使用炮口位置，操作员位置不替代炮口。原版 `ManTurret` 驱动跨层寻找炮弹/炮管、携带、装填、到达 `InteractionCell` 并操作，保持同一 Job 与预订。供电、冷却、装填、停火、强制攻击及友伤仍由原版负责，每发提交前复核几何。

普通近战限同层。范围盾采用单层高的有限圆柱边界，保留原版敌我、耐久和 EMP 决策；个人盾继续走原生伤害流程。切换查看层不改变射手或目标身份，在途弹丸不追踪换层后的目标。

## 迫击炮、投掷与撞击

迫击炮保持原版水平最大/最小射程、散布、装填和消耗。炮口列检查本层及所有上层楼板/屋顶；本层无顶不等于露天。

连续三维二次曲线同时供预判和实际扫掠使用。曲线允许越过墙和低掩体，但先遇到楼板、屋顶或建筑就撞击。**起点和终点同层也检查上层空间**。原版散布生成真实落点后固定曲线；落在空洞时继续寻找下方有效地面。

可指定其他楼层的区域格进行轰击。预判被屋顶截住时显示障碍和截断轨迹；这不把屋内隐藏实体变成自动目标，也不承诺落进屋内。高爆、燃烧、烟雾、EMP、灭火等弹丸在实际撞击处进入自己的原版效果。跨地图炮击继续沿用原生入口。

2026-10-21 接入原版 Verb_Jump 的跨层选点、预热、逻辑飞行与落地：沿平台边缘跳跃，无需步行路线；真实楼板、屋顶、地表与人物净空阻挡整条弧线。高度差计入跳跃射程，同层保留原版流程。携带物、队列与在途保存由原生持有链和附加逻辑状态共同恢复。

## 爆炸、气体、热量和火焰各自传播

这些系统复用既有实现，不把射击掩体概率套到介质传播上。

**爆炸：** 单个原版 Explosion 使用三维半径、距离、到达时间与遮挡；不在每层复制完整爆炸。覆盖在起爆时冻结，新破口只影响后续事件。沿用原版实体去重和待处理格，火、气体、生成物及热量落在实际覆盖位置。低掩体不作为全高防爆墙，也没有独立沙袋减爆伤倍率。冲击绕弯、独立破片和同次贯穿未加入。

**气体：** 通过开放通道按浓度差逐步交换，源扣目标加；生成与消散另算。完整楼板阻气，关闭通道停止后续交换但不清空已有浓度。保留原版各气体特性，包括 BlindSmoke 不扩散及 DLC 掩码；不统一增加上浮/下沉。沙袋与路障不因挡弹而封气。

**热量：** 保持现有跨层热交换；关闭明火通道仍可慢速导热。

**火焰：** 每次原版蔓延回调，对允许传火的楼梯口、井口或破洞向上/向下各至多选一个候选。概率分别为目标原版起火概率的 **20% / 5%**。出口有承载面就尝试该格；空洞则选择周围一格内无遮挡的合法承载面。完整楼板、屋顶、关闭通道阻明火；禁止 Pawn 走楼梯不封火。

新火由原生 `FireUtility` 创建，使用材质可燃性，不在空中或不可燃格生成。新火不在同一次回调继续串层；后续更新读取结构破口。原版消防、危险、寻路和保存使用真实火所在层；关闭通道不灭已有火，高温起火保留原版。不新增氧气、闪燃或燃烧碎屑。

## 自定义掩体高度

给目标 ThingDef 的 `modExtensions` 追加（不要替换其他扩展）：

```xml
<li Class="RimLayers.Combat.CoverHeightExtension">
  <height>1.0</height>
</li>
```

高度使用逻辑格单位，范围 0–3；这是战斗几何配置，不改变二维 `fillPercent`。原版沙袋/路障补丁位于 `Patches/CombatCoverHeights.xml`。

## 存档与验收入口

每次发射在原版扣弹前固定本次弹药类型；空炮和扣弹后的迫击炮仍保持曲射类别及原射程。弹丸额外保存不可变起止点、曲线高度、实际发射实体、扫掠进度及提交状态。原版 Projectile、操作 Job、弹药、冷却、火与 GasGrid 保持各自唯一存储；重载不重新抽散布、发射、消耗或开始爆炸。

运行命令（游戏根目录）：

```powershell
dotnet build Mods/RimLayers/Source/RimLayers/RimLayers.csproj -c Release
dotnet run --project Mods/RimLayers/Tests/CombatGeometryTests -c Release
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario combat-3d -AllDlc
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario combat-manned -AllDlc
```

`combat-manned` 分别从取弹中、已发射炮弹在途的原生保存检查点重启游戏。所有运行使用 `Tests/Artifacts/<run>` 独立配置，程序集变化后重新启动；不修改玩家存档/启用列表。具体结果在下节逐项记录。

本轮接入原生投射物 Verb 与炮台；除原版 Verb_Jump 外的非投射物特殊 Verb、第三方自定义战斗框架（包括 CE）需单独适配。大规模战斗的长期性能不由小场景验收推导。
