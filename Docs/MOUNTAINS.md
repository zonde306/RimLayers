# 山体多层：进入、采矿和旧层迁移

基准：RimWorld 1.7.4982 rev1280，0.1.4 开发候选。山体仍位于同一张真实 Map，地表及上层合计最多三层，按需追加。0.1.5 另支持 B1、B2，见 [地下层](UNDERGROUND.md)。

## 从山侧进入二层

在山外完成楼梯或单层电梯，再沿有下层屋顶支撑的位置铺结构楼板，接到二层山壁。使用原版“开采”指定挖开山壁即可进入；继续开采会形成隧道，可以搬矿、铺装修和建造，不需要山内另设入口。道路断开后工作等待重新连通，天然隧道不会随道路坍塌。

- **薄顶岩**：按普通屋顶提供支撑，上面是空域，必须自己铺结构楼板。
- **厚顶岩**：新增层有不可拆天然岩石楼板、可采岩体和矿脉，以及原版厚岩顶。
- 地面厚顶岩轮廓向上延伸；采矿只腾出所在层空间，不挖穿天然楼板。
- 可平滑石面及铺设装修。移除装修恢复铺装前的石面，包括原版采矿产生的 RoughHewn 石面。
- 厚岩顶的支撑和塌顶仍由原版处理，塌顶不删除天然楼板。天然楼板不是飞船基架，不随船移动。

矿物不是地面矿脉的复制品。每层依照原版矿种权重、矿簇大小、山地密度、地图生成预设和适用的非起始地图难度倍率独立生成；数量使用一层的逻辑面积，矿格限定在山体内。空间不足时少生成，不向空域或玩家建设里挤矿。开采产物、收益与连矿指定沿用原版；读档或重复迁移不刷新资源。

## 从下层向上开挖

在厚岩顶下建楼梯或单层电梯。蓝图和供料不创建楼层；到完工阶段才准备上一层。

出口有岩体或矿物时，框架显示“等待竖向开采（采矿工作）”，材料不会被销毁。启用殖民者的采矿工作后，矿工从下层施工位置挖通出口；再由建筑工完成框架。矿工和建筑工可以不是同一人。竖向开采操作真实上层 Mineable，使用其原版采矿伤害、速度、经验和产物，产物留在上层。

取消工作、征召、换人和保存加载保留岩体的实际损伤。建筑等非采矿障碍需要自行清理。直接生成或安装成品楼梯也不会免费清岩。垂直电梯需要逐层建站，不自动挖通整条井道。

## 已有空白上层如何补山

先另存新槽，切到需要补生成的上层，在楼层面板点击 **“补生成山体…”**。

预览中绿色是可补格，黄色是跳过格。确认后仅在未使用空域添加天然楼板、岩石及矿脉；已有楼面、实体、屋顶、区域、规划和任务指定不会被覆盖。提交前再次检查冲突，操作不自动保存。

矿脉先按完整楼层规划，再裁剪至本次可补区域；方案和处理状态保存。分次补生成不会重新抽矿，也不会填回已经开采的格子。未扩层旧地图无需此操作，首次正常追加楼层会自动生成山体。

## 实现与保存

`MountainService` 由 `LayerMapComponent` 唯一持有。保存山体轮廓、石种、分层矿脉方案、已处理格和天然楼面事实，不重复保存原版 Mineable 或 Job。旧档没有山体节点时初始化为空状态，不在读档时改写已有层。

扩层的新增实体与山体事实纳入原有网格事务，失败时先撤销新增岩体，再恢复布局、缓冲和塌顶队列。显式迁移另保留原迷雾和房间气候用于失败回滚。完整天然楼面进入既有结构、弹道及天空遮挡查询；岩体和采空后的同层房间沿用原版机制。

### 已核实的原版接入

- `GenStep_RocksFromGrid` 提供矿物预设上限、密度及起降例外；`GenStep_ScatterLumpsMineable.ChooseThingDef` 选择矿种；`GridShapeMaker.IrregularLump` 生成形状。适配层只限定逻辑面积和候选格，不直接对扩容后的整图调用矿物 Generate。
- 山侧开采使用原版 `MineAIUtility`、`JobDefOf.Mine` 和 `JobDriver_Mine`，接近模式为 Touch，不要求岩体格本身可行走。
- 竖向 Job 改变接近位置，每次敲击调用原版 `JobDriver_Mine.DoDamage`，保留真实 Mineable 的损伤、收益累计和矿脉指定行为。
- 原版 `PathFinderMapData.GatherData` 每游戏 tick 最多采样一次。诊断造景批次结束后推进一 tick，再下达采矿命令，不把同 tick 造景的旧缓存当作寻路实现故障。
