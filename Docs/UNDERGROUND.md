# 地下层：向下开挖与虫巢

基准：RimWorld 1.7.4982 rev1280 / Waylith / .NET 10。RimLayers 0.1.5 开发候选。

## 从地表逐层向下开挖

在“结构”中建造 **向下楼梯**，或研究自动门后建造 **向下单层电梯**。蓝图和供料不生成地下；进入完工阶段才准备紧邻下一层。到 B1 后，可以用同样的方法继续向下挖。默认地下上限为 B2，可在设置中调为 0～9 层，并受全局额外楼层额度约束。

出口有岩石或矿物时，框架保留材料并显示“等待竖向开采”。启用采矿工作的殖民者会从入口侧开采真实岩体，建筑工随后完成连接。原版采矿速度、经验和产物保持不变，产物留在被开采的地下层。中断、换人和重启读档保留岩体损伤；直接安装成品也不会免费清岩。

出口本来就是洞穴时，不需要额外采岩。水面或其他不可用出口不会被自动填平，材料留在框架中；取消并另选位置即可。拆除楼梯或电梯不删除地下层，不恢复矿物。

F7/F8 和面板按真实高度切层。地下层显示 B1、B2……（中文为地下 1、2……层），不是追加存储带的编号；落点按钮返回该通道另一端。

## 垂直电梯也能直接向下开井

选中已建成的 **垂直电梯站**，点击 **向下开挖**。同一座地面站也可同时执行 **向上扩井**，不必另建向下楼梯。矿工清理出口及相邻施工位，之后自动放置下一层站点蓝图；仍需按原配方供料、建造。施工期间通过起点站慢速进出，下一站建成后切换为正常电梯通行。

向上需有受支持屋顶，向下仍遵守下列地形限制和设置配额。逐层扩展、施工位和取消规则见 [电梯使用说明](DECKS-AND-ELEVATORS.md#同一座地面站向上向下扩井)。

## 哪些位置不能挖

- **IceSheet 冰盖、SeaIce 海冰整图禁止**，裸岩位置也不例外。
- 其他地图的水、冰、熔岩、桥面、基架和悬空位置不能作为开挖入口；铺装修不能掩盖不合法基底。
- 地表及地下可以向下开挖，地上楼层不行；最深层取决于设置，硬容量为 B9。
- 原生独立地下 Map、PocketMap 和太空 Map 不纳入此次扩展。
- 地下不能建造逆重飞船引擎/基架或作为起降位置。现有地上飞船功能保留。

地下天然石面可以平滑、装修，不能拆成空域。原版采矿留下的 RoughHewn 石面同样是合法岩石基底。普通开采不会挖穿楼板；天然厚岩顶仍按原版承顶与塌顶机制处理。

## 深钻与地质扫描仪

地面穿透扫描仪和深钻只允许建在**地表层和已开挖的地下层**；地上楼层（含飞船甲板）会被拒绝并提示 `RL_DeepResourceGroundOnly`。地下层天然带厚岩顶，因此在那里放开原版"扫描仪不能有屋顶"的限制；地表层仍要求露天，冰盖/海冰/太空等无基岩生物群系照旧不可用。

扫描结果只写进扫描仪自己那一层：候选区是该层经 10 格内缩的矩形，矿簇形状、矿种权重、簇大小和信件沿用原版。深钻读的也是本层那一格，21 格径向取样不会读到相邻层的隔离带。深钻资源覆盖网格按当前查看层过滤，切层后不会把地下矿画到上层楼板上。

## 岩层、洞穴与虫族

地下保留在同一张 Map 内。连续岩层、石面和厚岩顶采用原生地下规则；石种使用 RockNoises 与 RocksFromGrid 的选择机制，洞穴调用原生 MapGenCavesUtility.Dig 闭合洞穴算法，矿种和矿簇调用原生选择及形状助手。矿量以单层逻辑面积计算，读取 Underground_RocksFromGrid 的配置及适用难度倍率，不把整张扩容地图当作一个大矿区。

每层由地图种子和深度独立派生种子，不复制地表矿物。生成完的岩体、矿物、虫巢及其状态由原版实体保存；生成完成标记和天然楼面事实另存，读档和重复建入口不刷新资源。

初始洞穴隐藏在原版迷雾中。探索虫巢沿用原版 CaveHives 的面积计数、候选和创建方法，遵守难度开关、虫族派系与场景禁用设置；原生结果可以没有虫巢。虫族是真实 Pawn，保留原生 Lord 与战斗行为，连通通道后可以跨层追击。

后续虫灾仍由原有故事叙述系统调度，不按地下层数额外触发事件。已探索区域需要满足原版厚岩顶、温度、建筑距离、空间与难度条件。建筑距离、周边岩体和无顶距离按实际所在层计算，隔离带不参与候选。

地下不受日照和雨雪影响，初始室温为 15°C；之后沿用房间温度及已有连接器交换规则。电力、空气、热、声音和火焰按真实相邻层连通；地下边缘不是世界出口，天空投送不能落到地下。

## 地下生态

新生成的地下城会额外布置砾石土壤、蒸汽间歇泉与洞穴植物。全部复用原版定义，不新增也不修改任何 XML Def；缺少对应 DLC 时该植物自动从池中消失。

土壤取原版 Gravel（肥力 0.7，带 GrowSoil 与 Diggable 标签），只铺在洞穴地面：实心岩保留可开采性，岩浆与冷却岸保持不变。洞穴地面原本是石面岩的 implied terrain，肥力硬编码为 0，这是原版 `WildPlantSpawner.CheckSpawnWildPlantAt` 拒绝一切植物的唯一硬门槛；铺上砾石后，原版自己的洞穴植物重播规则也随之生效，不需要额外的 Harmony 补丁。

植物池由 defName 决定：Glowstool、Agarilux、Bryolux、Plant_Timbershroom，以及装了 Odyssey 时的 Plant_Psilocap、Boomshroom、Plant_Willowgill。初始布置走 `WildPlantSpawner.SpawnPlant`，因此每株都是正常的、可生长可收获的 Plant，和自然生成的没有区别。布置在 `afterRegions` 阶段执行，因为原版生成植物要求区域已建好；与虫巢共用该阶段，**虫巢先、植物后**。顺序不能反过来：Odyssey 的 `HiveUtility.SpawnExtras` 会在每个虫巢周围抹一片约 30 格的 `InsectSludge`（肥力 0），先种植物就会被这层烂泥顶掉，砾石格数也对不上。植物因此只落在虫巢之后仍然是砾石、且没有占用物的格子上。

蒸汽间歇泉使用原版 SteamGeyser，按面积和每万格数量换算，要求 2×2 全落在空旷洞穴地面、彼此至少 20 格，并避开虫巢候选格。间歇泉带 `blockPlants` 且不再是可种植地面，因此其上不会长植物。

所有计数由层种子与深度派生，同存档重放一致；每层的实际结果写入 `EcologyGenerationRecord`（土壤格数、间歇泉数、每种植物的株数），读档不需要重扫地图。

## 存档与接口

布局版本升级为 2。LayerId 是稳定存储带 ID，Elevation 才是物理高度。地表一直是 ID 0；新带只追加，不平移旧 Pawn、建筑、区域、预订或坐标。

旧版本 1 档按原编号恢复高度 0/1/2；读档不生成地下。正常保存会写入版本 2，升级前请另存新槽。楼层档持续需要 RimLayers。

- LayerLayout 提供 ElevationOf、TryGetLayerAtElevation、TryGetAdjacentLayer 和 OrderedLayers。
- EnsureElevation 准备指定高度；原 EnsureLayerCount 仍表示准备地表及指定数量的上层，不把地下计入完成条件。
- 战斗场景的层号是物理高度，可以为负数；弹丸实体的存储层 ID 保持独立。
- ShipStructure 的 Bottom/Top 是物理高度，飞船载荷按相对高度编码，着陆时再映射到存储带。
- 原生生成网格、RockNoises 和随机状态采用作用域恢复；扩容异常撤销新实体、天然楼面及生成标记，恢复旧布局和网格。

## 复现与证据

使用独立配置和存档启动测试；不要改玩家启用列表。修改 DLL 后必须重启游戏。

```powershell
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario underground
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario underground -AllDlc -BootstrapLift -MapSize 250 -TimeoutSeconds 300
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario deep-resources -TimeoutSeconds 300
pwsh -NoProfile -File Mods/RimLayers/Tests/Run-V1.ps1 -Scenario deep-resources -AllDlc -TimeoutSeconds 400
```
