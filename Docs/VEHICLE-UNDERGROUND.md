# 用载具升降机往返地下

## 从地表连到 B2

1. 用现有向下楼梯或人员电梯开发 B1、B2。扩层仍受地下层数、全局配额及地形限制；载具升降机不会自行生成地下层。
2. 在地表、B1、B2 的同一逻辑位置各建一座 **9×9 载具升降机站**。先挖走地下站内的岩石，保留四角外侧的承重地面，并挖出整车能通行、转向的出入口。
3. 选中地表站，点击 **“开凿下层井段”**；再在 B1 站执行同一命令。矿工在上方站工作，逐格开通与紧邻下站之间的井段。每格需要 600 工作量，一个井段共 81 格；采矿速度影响工期。工作与进度可暂停、保存并重启续行。
4. 给经过的各站供电（每站 1800 W）。井段全部完工后，车辆可双向通行，也可直接从地表到 B2，但不能缺少中间的 B1 站。

车完全驶入并停稳后，使用车辆的 **“前往楼层”** 命令；跨层自动移动也会规划升降机路线。停电时保留原车并暂停，恢复供电后继续。

### 开凿前要留意

- 只开凿上方站的干燥天然地面。上方站内的铺装、地基和楼板，以及下方站的人工屋顶，必须先人工移除；命令不会顺带拆除它们。
- 接收站的地面可以铺装；若以后还要继续向更深层开凿，再移除该站的铺装。
- 两站载车区内不能有车辆、岩石或其他阻挡物。普通人员可以施工；实际运输时，任何人员进入井道都会让升降机等待。
- 井段未完成不能通车。黄色选中轮廓标出尚未贯通的格子，检查面板显示进度和阻塞原因。
- **停车位置必须让整车离开载车区。** 车头或车尾仍占井口格时，下一辆车会等待，不能只看车辆中心点。
- 每层高度为 3 米。机体高度超过净空的车型不能驶入；不会缩小车辆占地来强行通过。

拆掉已开凿的站台会留下真实井口，不会重新长出天然楼面。可在原位置重建有四角支撑的站台。运输中站点失效时，优先返回合法出发站；不能卸载则继续保存原车辆，从恢复命令处理，不复制车辆或把它改放地表。

## 实现与存档

- `Vehicles/VehicleShaftExcavation.cs`：现有站台上的显式施工命令、采矿 WorkGiver/JobDriver、逐格提交及保存进度。原生 Frame 消耗材料并完成站台；本命令只处理已建站之间的井口。
- `VehicleFacilitySpace` / `VehicleRoutePlanner`：地下站的建造与重建、完整井道和每层可收回平台检查；暂停施工期间不提供通行边。
- 地质记录和楼层 ID 不变；物理地面查询按实际井口与平台判断，拆站后的地表和地下开口不再被当作实心地面。
- 钢铁地平线的网格 `FullRotation` 可能与连续车身角度不同。增强适配器在原生自动驾驶期间读取真实 `CompVehicleGroundMotion.Heading`，避免以假想的 45° 跳转计算转向扫掠；基础适配器仍可独立使用。
- 旧站没有新增施工字段时，按“未下达施工命令、工作量为 0”读取。井口和平台使用原生地图地形、屋顶保存；运输继续保存原车辆、乘员、货物及原任务。

## 地下专项实机证据

基准：RimWorld **1.7.4984 rev1242**，钢铁地平线 **4.9.2**，Technical Vehicles 的 **TC_BigBread（2×5）**。独立数据目录：

`Tests/Artifacts/vehicle-ground-20261022-031429`

四个独立游戏进程共 **73/73** 项通过：生成/施工中保存 20 项，重启完工及停电中保存 19 项，运输重启与受阻恢复保存 20 项，再次重启恢复与往返 14 项。包括：

- 厚岩顶与天然楼面在建站后保持不变；未开凿、部分开凿和缺中间井段都拒绝通车。
- 原生矿工工作、暂停/续工、工作量与 Job 跨进程保存；人工屋顶和上方铺装受保护，下方铺装不影响其上方井段施工。
- 地表到 B2、B2 回地表、指定 B1 停靠；双车 FIFO、整车退出井口、完整井道内人员阻挡、停电续行。
- 目标站损坏、出发站被堵、全部站点移除、重建井口和人工恢复；原车、原乘员和 37 钢材不丢失、不重复；装卸及读档不会重置燃油与部件损伤，正常驾驶仍消耗燃油。
- 实际检查施工按钮/进度、B2 运输机体、B1 到达选框和楼层标签；自动运输不强制切换视角。

场景先准备已挖好的地下车库，再通过真实 Frame 完工、真实采矿 Job 和真实载具寻路执行。隔离测试矿工使用 200 倍采矿速度，以缩短工作等待；正式游戏不加载该测试 Hediff。每个游戏 tick、采矿提交和存读档流程仍走实际实现。

报告中没有场景运行错误。完整启动日志另有本机已有的两个 Vulkan 外部覆盖层路径错误和三个未启用 MOD 的重复包 ID 提示；未修改这些外部安装。拆除测试站台后，悬在井口上的测试电缆会触发预期的无支撑建筑警告。
