## 使用方法

只启用一套载具框架。当前验证组合为钢铁地平线 **4.9.2**；正常启动自动识别能力，无需测试启动参数。原版 Vehicle Framework 1.7 尚未适配，不要同时启用两套框架，也不要将原版 1.6 DLL 放进 1.7。

- **坡道**：在结构菜单建造同起点、同方向的 1×6 模块，并排加宽到足以容纳整车。提前清理上方净空，准备有支撑的出口平台。不能沿坡面纵向拼长或中途转弯；多层通过平台转接。
- **载具升降机**：在同一位置各层建造 9×9 站点、连成完整竖井并供电。自动任务按通道预约进入；手动驾驶使用“前往楼层”。停电续存原车，恢复供电继续。站点损坏时优先返回来源；没有合法出口时，在楼层面板恢复原车，先重建站点并清空占地。
- **地下升降机**：地表、B1、B2 同位置建站后，在每个上方站执行“开凿下层井段”，由矿工逐格贯通；不能只建站就直接穿过厚岩层。[施工、存档与专项验收](VEHICLE-UNDERGROUND.md)。
- **飞行**：使用框架原有起降、WASD 和移动命令。每层相隔 3 米；飞机自然跨层，高于最高建筑层不会自动扩层。固定翼需要足够的进近与转弯空间，不能用小型直升机停机坪代替机场。
- **世界返航**：在目标楼层选落点。被新建筑或其他障碍占用时，原机留在框架世界/到达对象中；从世界载具命令或楼层面板“等待降落的载具”重新选点。

机体净空默认 3 米。车型作者可在 VehicleDef 的 `modExtensions` 中加入：

```xml
<li Class="RimLayers.Vehicles.VehicleClearance"><height>4.5</height></li>
```

该值为机体高度（米），不改变框架的长宽或动力学。水面航行、CE 跨层战斗及全面武器弹道不在本次范围。不同提供者的存档不可据此直接互换。

## 已实现的地面通行

- 基础适配器只绑定 Vehicles 核心；可选 SteelGroundMotionAdapter 和 SteelManualAdapter 独立绑定 LocalUpgrade。实际运行包、类型归属及关键签名匹配后安装。原版 1.6 不作运行依赖；未来原版 1.7 仍须另行验证。
- 旋转整车占地、保守转向扫掠、连续三维坡面扫掠、3 米层高、可选车高扩展（默认 3 米）。占地中心沿用框架对奇偶尺寸及方向的锚点。
- 可建造的 1×6 坡道模块：同起点同向并排加宽，双向通行，坡面不掉头；完整坡面运动而非终点瞬移。断开模块时保管原车并尝试返回合法入口。
- 可建造的 9×9 净载车升降机：连续同位置井道、四角支撑、主动清理的上层开口。只在空洞上安装自身甲板，不拆除既有楼板、屋顶或岩石。
- FIFO 整通道预约、进出站占用保护、相向排队。自动驾驶的层内路段仍由框架寻路；共用图保留到达朝向、最终目标和原任务。临时阻塞会等待，并尝试经框架生成且经全车扫掠复核的两段绕行。
- 车辆完全驶入、原生到达回调停稳后，升降机接管原 Pawn。断电暂停，全井道内有人或其他车辆也暂停；失效或取消优先返回出发站。无法卸载时原车继续保存在地图级 ThingOwner，可清理出口后恢复。
- 保存设施引用、车辆引用、最终任务/目标、阶段、队列票据、坡道连续进度、绕行中间点和轿厢高度；读档重建预约及层内路径。不保存第三方私有状态副本。
- 动态扩层等待原生路径工作完成，暂停本图原生区域线程，重建全部尺寸相关车辆网格；事务失败恢复原数组与原任务。原版 PathFinder 的回滚另需 Notify_MapDirtied，避免旧缓冲区收到新增地图段的增量索引。
- 地面提交在原坐标系停止路径，再更新原车占地、原生传送通知、连续位置和绘制基准，避免地图存储段差值进入撞击计算。
- 手动坡道运行钢铁地平线原生驾驶 tick，保留发动机、质量、加速、倒车与制动计算；坡道接管方向约束、空间检查和坐标提交。读档后保持安全位姿，重新启用原生手动驾驶可接续。
- 升降机有“前往楼层”、取消、恢复及排队/恢复状态显示。预览标记入口、出口、支撑和净空冲突。轿厢内绘制原车的框架材质，不创建代理 Pawn。自动运输不强制切镜头，手动跨层跟随受控车辆。

### 已发现并修正的问题

- 框架付款与剩余格成本同为 float.Epsilon 时原生寻路停滞：仅在运动组件已支付全额且剩余值为 subnormal 时归零。
- 升降机刚卸车即释放预约，后车会向未清空的轿厢寻路：保留通道占用至全车驶离，并在原生寻路失败时由主线程重试。
- 动态车辆占用或断电不能被当成设施失效；有效性检查分离结构与暂态阻塞。
- 原生接管及 JobGiver_AwaitOrders 都会调用 StopDead。手动坡道没有原生 Goto 可取消，普通刹车/离开接管保留坡上位姿；显式取消仍安全退回入口。
- BigBread 旧测试把终点停在坡道转向空间附近，停车后相向车无法安全掉头绕行；旧失败报告保留在 222933、223235、223437。现使用有支撑且位于通道之外的停车区。独立动态路障场景随后暴露停车过晚；增加原生路径前段的整车扫掠后，230934 已实际绕过墙体完成原目标。未缩小路障或车辆占地。
- 测试输入需同时给出油门/方向与刹车状态，否则原框架 UI 的输入捕获会留下刹车状态。此处理只在独立测试驱动中。

## 本轮接口证据

- 当前原版 `Map.FinalizeLoading`（`0600145A`）先恢复 Pawn，再调用 `GenSpawn.SpawnBuildingAsPossible`（`060038B1`）恢复建筑。后者遇到 Pawn 与不可通行建筑重叠会退款建筑。适配只恢复仍由同一坡道运输持有合法占用的原模块，不扩大普通建造许可，也不拆除其它对象。

- `VehicleComponent.SetHealth(float)`（`0600034E`）通过原生健康变化事件设置实际部件伤损，用于独立测试，不操作玩家车辆。

- 旧版 Mosquito 的 MoveSpeed 明确为 0（禁止地面滑行），钢铁地平线用它判断缺动力及手动驾驶许可，导致起飞即坠毁或无法接管。只在分层地图中为这种零滑行速度飞机保留实际在线、燃油、部件效率和驾驶员检查，不改变其地面行驶能力。
