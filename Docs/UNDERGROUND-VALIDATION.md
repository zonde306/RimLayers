- Release 构建：0 警告、0 错误；输出没有复制游戏、运行时或 Harmony DLL。
- XML：36 个元数据、Def 与语言文件解析通过，15 个显式 Def 身份无重复。

- 原有 NavigationTests 8 项、GasExchangeTests 与 HeatExchangeTests 各 100000 个随机样本、ShipTopologyTests 10 项通过。
- 已查看地下实景截图：天然岩壁、洞穴与迷雾保留，B2 楼层面板、室内 15°C 和自然楼面提示可读。截图位于对应地下记录目录的 underground-unexplored.png、underground-explored.png。切层检查使用共享切层入口；实体键盘事件未自动化。

## 规模与异常恢复

250×250、存储映射 [0,-1,-2,1,2] 的有效样本：

- 地表→B1：2441.6 ms；B1→B2：2625.4 ms。
- 已有两层地下后追加两个上层：2154.1 ms，其中绘制约 1656.5 ms。
- 五层、100 个实际 Pawn 的短样本：599 个原生 tick 合计 859.43 ms，平均 1.435 ms/tick。该场景包含野生动物、虫族与三名殖民者，不代表百名工人的长期工作负载。
- 故障注入后的大图回滚恢复了原布局、实体数和 Lord 数，但仍有约 84 秒的同步暂停。普通向下扩层不执行这一故障分支；异常日志出现后不要强退正在恢复的进程。

## 原始反例与修复

1. v1-underground-20261020-205927 暴露 RoughHewn 石面被误判，已经挖通的 B2 出口仍保留 Frame。通过原生岩体 naturalTerrain/leaveTerrain 及平滑地形关联修复；同一存档重放通过。
2. 早期切层断言没有先设定起始视图，修正夹具为从 B1 上切到地表。
3. v1-underground-20261020-211103 的大图虫灾夹具在局部 100×100 范围选中了单格开采孔，而非合格洞穴；改为选择真实房间并推进一 tick 刷新原生缓存。没有降低虫灾的空间、温度或迷雾资格。
4. 普通撤销岩体会逐块触发迷雾与塌顶扫描；事务撤销改用原生 WillReplace，大图仍有上述恢复暂停。
5. underground-mixed-ship-replay-20261020 首次夹具漏放驾驶台，原生飞船捕获空引用；补齐真实驾驶台后，使用同一地下存档重放，28 项通过。

深钻与地质扫描仪本轮只核实 Core 与全部官方 DLC 下的按层行为：第三方矿物/扫描 mod、CE 的深钻改写和其他多层框架未验证。扫描仪在地下放开屋顶限制是本轮明确的产品决定，不是原版行为。

未新增 CE、第三方地质/虫族/飞船框架或多年运行适配；原有相关支持边界不变。使用前重启游戏，先另存新槽；新版布局正常保存后写入版本 2。
