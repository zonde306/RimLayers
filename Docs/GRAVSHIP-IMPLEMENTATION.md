# Odyssey 多层逆重飞船

更新：2026-10-19。状态：开发候选；已有目的地图运行时扩容已通过隔离验证并接入出发准备。


开局已有飞船地图若尚未扩层，不再禁止放楼梯：第一座楼梯完工时按需扩容并建立出口，见 [楼梯按需创建](STAIR-BOOTSTRAP-VALIDATION.md)。这不改变合法核心的随船收集限制。

## 使用与当前边界

启用 Odyssey 后仍使用原版逆重核心、驾驶台与起降流程。不添加第二套飞船实体或跨图预订。只对玩家拥有、核心完整且具有原版有效逆重基底的飞船收集楼层；燃料、推进器、驾驶台、冷却、目的地航程和原版警告继续由原版仲裁。只摆上层建筑、没有核心或没有有效基底，不会激活这套运输。

- 船底以所属船体的最低甲板为准，核心可位于任意层；上下甲板通过实际基架与屋顶支撑连接。落地最低甲板对应选定楼层，核心保留相对高度；新地图仍默认地面。
- 原版 `ValidSubstructure` 保留核心甲板的二维查询；`ShipStructureService` 维护全船归属和共同承载计数。原版设施在同一船体内按逻辑距离跨层链接，数量上限全船共享。超载或多个核心归属冲突会明确阻止起飞，不删层、不漏载。
- 船外上层结构不随船。跨越本次移动边界的建筑在确认后、原版封装前销毁，原容器内容与框架材料留岸；跨界区域仍必须先拆分；墙面附着物按原版支撑墙归属。落点同时检查高层地板、屋顶和实体完整占地。
- 新目的地图只准备船体所需楼层，已有多层地图可返回。已有未扩层的地表/太空目的地图在确认出发后、原版扣油之前扩容；选址及待确认弹窗不改地图。扩容失败则取消出发，口袋/地下地图继续拒绝。证据见 [运行时扩容验收](LIVE-EXPANSION-VALIDATION.md)。
- 原版起降动画保持基准甲板的二维捕获，不宣称三维叠层动画。切换当前地图后楼层服务、梯口和观察层归属新地图。

楼层存档仍要求 RimLayers。开发候选请另存新槽，不覆盖唯一存档。

## 原版保有实体所有权

当前基准为 RimWorld **1.7.4982 rev1280**，主程序集 MVID `a46e6f45b6164261bb63a9471bf7402a`。

`GenerateGravship` → 原版 `Gravship` 构造与收集 → 原版 PreSwapMap / DeSpawn → 原版世界对象航行与保存 → 原版着陆生成与 PostSwapMap。每个 Pawn、物品、容器、工作台和区域只有原版这一套所有权与保存入口。

仅在有明确核心的收集作用域内扩大 `TransferZones`、`CopyCellContents`、`CopyAreas` 的候选格。保留原版基底集合，不让楼层坐标带撑大船体边界或落点预览。原版载荷相对位置规范化为 `(dx, relativeLayer, dz)`：这里的 y 只在飞船包内编码相对层号，真实 Map 坐标仍为 y=0。原版旋转函数保持 y，只旋转 x/z；落地时按目的地图自己的 stride 解码。

补充保存 `rimLayersShip` 版本 2：实际甲板跨度、核心相对甲板偏移及各随船格原始 top / under / temporary TerrainDef；foundation 继续由原版载荷保存。读取版本 1 时采用旧核心基准（偏移 0），之后写版本 2。实体仍由原版 things / pawns 字典深保存，不重复保存；允许区、区域优先级、Bills、容器和随身物品沿用原版。

## 关键顺序

1. 起飞预检只读分类跨界建筑/区域，原版确认仍需通过；跨界建筑另有损失确认。封装前再次扫描并销毁跨界建筑，只转移完整对象。
2. 飞船封装后，清理随船格与无楼面的船属支撑屋顶，再还原地图侧普通停机坪和原区域/指令；其他普通结构不进入载荷。原版是否保留原地图仍取决于逆重锚等原版规则。
3. 目的地预览和确认均复核上层占地。确认被拒绝时保留原落点标记供重新选择，不开始着陆动画。
4. 原版贴地形前恢复结构事实与支撑屋顶；贴地形后恢复完整表层、底层、临时地形与颜色，再让原版生成楼梯、建筑及 Pawn。这样既不触发空域 Pawn 纠偏，也不会让临时积水的原版承载回退吞掉木地板。
5. 原版放置结束后重建梯口、电力、空气、天空与路径代价；房间温度/真空恢复采用同一坐标解码作用域。
6. 原版完成着陆后释放飞行所有权。测试调用者必须像原版确认按钮一样释放已销毁的 landingMarker，否则它会再次深保存整个船。

## 模块与可检索入口

- `Source/RimLayers/Ships/ShipLayerData.cs`：合法性、候选收集、载荷编码、补充保存与投影。
- `Ships/ShipCapturePatches.cs`：原版收集入口、登船归属、原地图清理。
- `Ships/ShipProjectionPatches.cs`：原版地形、实体、区域与房间坐标的受限解码。
- `Ships/ShipLandingPatches.cs`：目的地、预览、确认、放置、切图与重建。
- `Generation/LayerGeneration.cs`：合法入站飞船的新地图分配作用域；普通 NPC / 太空地图不因该功能普遍扩容。
- `Diagnostics/V1Gravship.cs` 与 `Tests/Run-V1.ps1 -Scenario gravship -NativeShip`：真实原版流程、飞行保存、落地保存与重复飞行测试。

当前共存数据、蓝图归属及镂空支撑屋顶补充见 [实施契约](SHIP-COLONY-COEXISTENCE.md) 和 [验收](SHIP-COLONY-VALIDATION.md)。版本2增加可选 supportRoofs，原有相对坐标含义不变；覆盖记录与岸侧回收 ThingOwner 只随地图保存。
